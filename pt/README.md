# Bloxd Shader Packs — O Guia de Engenharia (PT)

**Guia completo e baseado em dados para criar shader packs do Bloxd.io (renderizador WebGPU).**
Construído com dados medidos do motor, uma tabela numérica completa de IDs de blocos,
dissecações de packs publicados e uma cadeia de validação local.

> Não oficial. Partes criadas com assistência de IA; verifique no jogo.
