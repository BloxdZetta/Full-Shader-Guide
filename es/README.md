# Bloxd Shader Packs — La Guía de Ingeniería (ES)

**Guía completa y basada en datos para crear shader packs de Bloxd.io (renderizador WebGPU).**
Construida con datos medidos del motor, una tabla numérica completa de IDs de bloques,
disecciones de packs publicados y una cadena de validación local.

> No oficial. Partes creadas con asistencia de IA; verifica en el juego.

| [III – Recetas](../en/03-recipes.md) | 12 recetas de producción con snippets WGSL |
| [IV – Realismo](../en/04-realism.md) | Números medidos: luz, niebla, agua, curvas |
